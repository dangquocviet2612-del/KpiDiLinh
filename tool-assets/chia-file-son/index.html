Excel

Lọc Excel và giữ nguyên định dạng

Làm theo 3 bước: chọn file, cấu hình lọc, rồi xuất kết quả.

Chưa chọn file
B1
Chọn file Tải workbook nguồn lên trình duyệt.
B2
Thiết lập lọc Chọn cột, giá trị và thêm nhanh mã nhân viên.
B3
Xuất file Gộp 1 file hoặc tách tự động theo cột.
Bước 1

Chọn file nguồn

Tải file Excel nguồn để bắt đầu xử lý.

Bước 2

Thiết lập bộ lọc

Áp dụng điều kiện AND giữa các cột, và OR giữa các giá trị trong cùng một cột.

Ví dụ: cột Mã CTV lọc các giá trị CTV01, CTV02. Không phân biệt hoa thường.

Thêm nhanh mã nhân viên

Tách riêng khối này để chọn dòng đích, quản lý và mã NV nhanh hơn.

Chọn dòng lọc đích rồi chọn quản lý và mã NV để thêm vào ô giá trị.
Tên cột Giá trị
Bước 3

Chọn chế độ xuất

Chọn cách xuất tệp sau khi đã lọc xong dữ liệu.

Sẵn sàng xử lý dữ liệu.

Lưu ý nhanh

  • Dùng đúng tên cột trong file Excel để bộ lọc chạy chính xác.
  • Nếu muốn tách nhiều file, hãy chọn chế độ tách và nhập đúng tên cột.
  • Tên file xuất sẽ giữ lại tên gốc để dễ tra cứu.
  • Workbook gốc không bị chỉnh sửa, chỉ tạo file mới để tải về.
